03 · use it

Find commands by the job in front of you.

These are shipped command families, grouped by intent. Run flotilla help for the complete flag surface.

Inspect

flotilla status [--json]

Read the detector snapshot and report each agent session's observed state and loop posture.

flotilla dash

Open the local fleet, goals, issue, parade, and research views on a loopback address.

flotilla quality show [--json]

Summarize recorded completion and gate quality by agent runtime and work class.

Coordinate

flotilla send --from <sender> <agent> <message>

Queue or deliver work to one coding-agent session and report the actual disposition.

flotilla dispatch-status <nonce>

Check whether a dispatch nonce was consumed, queued, delivered, or left undelivered.

flotilla dispatch-ack <nonce>

Record that this recipient durably handled a dispatch.

Start and recover

flotilla register <agent>

Attach a stable identity to a tmux pane so title changes cannot break routing.

flotilla resume <agent>

Start or restart a session from its host-local launch recipe.

flotilla recycle <agent>

Close a work chapter through a durable handoff, then relaunch and take over.

flotilla switch <agent> --to <runtime>

Move an agent session across configured runtimes with a fail-closed handoff.

Provision

flotilla workspace init <agent> --repo <path>

Create a worktree, host workspace, launch entry, and native agent instructions.

flotilla doctrine install <agent>

Install the fleet's operating doctrine into one agent workspace.

flotilla goals validate

Fail closed when the fleet goals graph is malformed.
