One coordinator for the agents you already run.

Flotilla is a coordination layer. You give one agent an outcome; it routes work to your other coding-agent sessions, preserves the record, and returns what needs you.

What changes

One place to direct work

You stop copying the same context across separate agent windows.

Work keeps a record

Delivery attempts, handoffs, and acknowledgments leave durable records.

Results return to one place

The coordinator gathers replies so you can review them without opening every session.

The three terms you need

  • Coordinator: the one coding agent you talk to. It routes work and gathers replies.
  • Agent session: a running coding-agent process with a defined responsibility. The CLI also calls this a desk.
  • Fleet: the coordinator plus the agent sessions it directs.

What flotilla does not replace

It does not replace Claude Code, Codex, Grok, OpenCode, Pi, aider, your editor, your repository, or your review process. It coordinates those existing tools and keeps their work legible.
